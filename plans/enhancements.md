# План: мультивалютные сценарии, дельта цены, мобильная версия

## Context

Три улучшения учебной игры «Банк в шорте»:

1. Сейчас сценарий захардкожен: USD/JPY, курсы 109.78 → 119.58, ящики USD/¥, тексты и викторина с числами кейса (src/main.ts: ~15 мест). Нужны разные валютные пары, чтобы жена прочувствовала закономерность («курс вырос ≠ прибыль») на разных примерах.
2. Баг: треугольник с изменением цены (`.ticker-delta`) показывает |rate − lastRate| — изменение за последний тик ползунка, а не общее изменение (src/main.ts:212, lastRate обновляется в setRate:198).
3. Мобила: единственный media query на 560px (мелкие правки шрифтов, src/style.css:463); ящики валют в 3 колонки (grid 1fr auto 1fr) на телефоне узкие, кнопки мелкие.

## Approach

### 1. Мультивалютные сценарии (рефакторинг)

Ввести тип `Scenario` и массив готовых сценариев; тексты шагов, расчёты, математику, викторину и слайдер генерировать из параметров сценария (вместо хардкода):

```ts
interface Scenario {
  id: string;
  pair: string;        // "USD/JPY"
  base: string;        // "USD" — базовая валюта (объём в ней)
  quote: string;       // "JPY" — котировка
  baseSym: string;     // "$" | "¥" | "₽"
  quoteSym: string;    // "¥" | "$" | "₽"
  baseEmoji: string;   // 💵 | 💴 | 💰
  quoteEmoji: string;
  entry: number;       // курс продажи
  exit: number;        // курс, до которого вырос
  digits: number;      // 2 | 4 (точность курса)
  amount: number;      // объём в базовой валюте
  sandboxCapital: number; // стартовый капитал песочницы в quote-валюте
  texts: {
    intro: string;    // Шаг 1: ситуация и мотив банка (своя формулировка задачки)
    wait: string;     // Шаг 2: на что ставит банк, ключевая подсказка
    rise: string;     // Шаг 3: требование клиента / почему рост = проблема
    result: string;   // Шаг 4: разбор и аналогия
    quiz: [string, string, string]; // формулировки 3 вопросов викторины
  };
}
```

**Каждый сценарий — отдельная задачка со своей текстовкой** (как разные формулировки задач в учебнике), не «те же шаги, другие цифры»:

- **USD/JPY** — исходный кейс жены: «Банк продаёт клиентский 1 млн долларов в йену по курсу 109,78…»
- **RUB/USD** — «Экспортёр принёс 100 млн рублей. Банк продал их за доллары по 0,0111, поставив на укрепление рубля…» (приоритетная рублёвая пара)
- **USD/RUB** — «Импортёр платит поставщику в долларах. Банк продаёт 1 млн USD за рубли по 90,0, ставя на укрепление рубля…»
- **JPY/USD** — «Банк конвертирует для клиента йены в доллары: продал 100 млн ¥ по 0,0092, рассчитывая на укрепление йены…»

Числа в текстах подставляются из параметров сценария, но формулировки, мотивы и аналогии у каждой пары свои. Викторина тоже использует формулировки сценария (`texts.quiz`) — вопросы звучат как отдельные задачки про эту пару, а не копии с подставленными цифрами.

- Селектор пар в панели сценария (и в песочнице — общий): **USD/JPY** (текущий кейс жены), **RUB/USD**, **USD/RUB**, **JPY/USD**. Пользователь: рублёвые пары важны, RUB/USD — предпочтительнее (идёт вторым после USD/JPY). Смена → сброс шагов и песочницы.
- Обратные пары (JPY/USD, RUB/USD) обучают: «курс вырос» — всегда про цену базовой валюты; продал базовую → рост курса = убыток.
- Реалистичные курсы: USD/JPY 109.78→119.58; RUB/USD 0.0111→0.0122 (рубль подорожал); USD/RUB 90.0→95.0; JPY/USD 0.0092→0.0102.
- Ящики, подписи, стрелки, PnL в quote-валюте — динамические (вместо хардкода USD/¥ в index.html и renderBoard).
- Слайдер: диапазон и шаг из сценария (`digits`, ±15% вокруг entry), вместо жёстких 90..140/0.01.
- Викторина: смысловые вопросы общие («почему рост — плохо», «при каком курсе ноль»), числовые подставляются из активного сценария.
- Песочница: стартовый капитал в quote-валюте, позиции в base-валюте.

### 2. Дельта цены

`.ticker-delta` должен показывать общее изменение от точки отсчёта, а не за тик:

- открытая позиция → от курса открытия (entry): стрелка/дельта согласована с PnL;
- без позиции → от стартового курса сценария/песочницы.
Убрать `lastRate`-логику (или оставить только для цвета тика).

### 3. Мобильная версия

Второй media query (≈640px) + усиление существующего:

- ящики валют вертикально (стрелка между ними), крупнее тап-зоны (min-height 44–48px у кнопок), кнопки на всю ширину, табы на всю ширину, толще ползунок, увеличенный padding панелей.

## Files to modify

- `src/main.ts` — Scenario-тип, массив сценариев, генерация шагов/викторины из параметров, селектор пар, дельта, динамические ящики
- `src/style.css` — адаптив под телефон (вертикальные ящики, кнопки, табы)
- `index.html` — селектор пар, динамические подписи ящиков (тексты валют)
- `scripts/check.mjs` — проверка формул для всех 4 пар (расчёт убытка каждого сценария)
- `README.md` — упоминание пар и ссылки

- Викторина — текущая структура QUESTIONS, вопросы параметризуются.
