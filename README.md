# 🏦 Банк в шорте

Учебная веб-игра-симулятор: почему «курс вырос» — это убыток для банка, который продал доллары (сел в шорт).

## Кейс из задачи

Банк продаёт клиентский 1 млн USD за йены по курсу 109,78 (расчёт на падение курса — это **шорт**). Курс вопреки прогнозу **вырос** до 119,58, клиент требует перевести доллары обратно — банк теряет **9 800 000 ¥**, потому что долларов у него больше нет и их приходится откупать дороже.

Игра показывает это наглядно: пошаговые сценарии-задачки с живыми «ящиками» валют, ползунок курса с мгновенным PnL, разбор математики, викторина и свободная песочница.

## Валютные пары

Каждая пара — отдельная задачка со своей формулировкой (как в учебнике):

- **USD/JPY** — исходный кейс: банк продал доллары за йены, курс вырос 109,78 → 119,58, убыток 9,8 млн ¥
- **RUB/USD** — экспортёр сдал рубли, банк в шорте по рублю: 0,0111 → 0,0122, убыток $110 000
- **USD/RUB** — импортёр, шорт доллара за рубли: 90,0 → 95,0, убыток 5 млн ₽
- **JPY/USD** — инвестор, шорт йены за доллары: 0,0092 → 0,0102, убыток $100 000

## Запуск

Игра опубликована на GitHub Pages: **<https://rkedjk.github.io/bank-short-game/>** — можно открывать без установки Node.

Локальный запуск:

```bash
npm install
npm run dev      # → http://localhost:5173
```

Сборка и проверка:

```bash
npm run build    # production-сборка в dist/
npm run check    # самопроверка математики кейса
```

## Стек
